# Wonders - Билеты на вершину

Проект веб-сайта для бронирования автобусных билетов по живописным альпийским маршрутам.

## О проекте

Wonders - это современный веб-сайт для поиска и бронирования автобусных билетов в Альпах. Проект реализован в рамках учебного модуля по фронтенд-разработке.

Figma макет: https://www.figma.com/design/Qq0LN905byLasCfNboVzU2/Module-1-Wonders--Share-?node-id=0-1&t=sIWsM0vWwHgRRTzO-1

## Цели проекта

Разработка полностью функционального лендинга для бронирования билетов с акцентом на:
- Чистый семантический код
- Адаптивный дизайн
- Интерактивные элементы
- Валидацию форм
- Кроссбраузерную совместимость

## Функциональность

### Основные возможности:
- Поиск билетов с выбором направления и дат
- Автодополнение станций из 50+ альпийских станций
- Интерактивный календарь для выбора дат поездки
- Адаптивный дизайн (1440px, 768px, 360px)
- Мобильное бургер-меню
- Валидация формы перед отправкой

### Страницы:
1. Главная страница (index.html) - форма поиска билетов
2. Страница подтверждения (bus-list.html) - сводка бронирования

## Технологии

- HTML5 - семантическая разметка
- CSS3 - Grid, Flexbox, анимации, кастомные свойства
- Vanilla JavaScript - интерактивность без фреймворков
- Адаптивный дизайн - mobile-first подход

## Ключевые компоненты

### Форма поиска:
- Тип поездки: Round Trip / One Way (радиокнопки)
- Станции: Departure/Arrival с автодополнением
- Календарь: Двухмесячный вид с выбором диапазона
- Пассажиры: Счетчик с лимитом 1-12 человек
- Кнопка: "Find My Alpine Ride"

### Навигация:
- Фиксированный хедер
- Бургер-меню для мобильных устройств
- Плавные скролл-ссылки

### Дополнительные секции:
- Статистика - цифры компании
- Галерея - адаптивная сетка изображений
- FAQ - аккордеон с анимацией
- Контакты - карточка с информацией
- Футер - ссылки и копирайт

## JavaScript функциональность

Реализованы следующие модули:

Автодополнение станций - фильтрация и подсказки для 50+ альпийских станций
Календарь - логика выбора дат, работа с диапазонами, валидация
Навигация - управление бургер-меню, плавная прокрутка
Валидация формы - проверка заполнения полей, корректности дат и станций

### Ограничения:
- Максимум 12 пассажиров
- Дата не может быть в прошлом
- Станции отправления и прибытия не должны совпадать
- Для Round Trip - дата возврата не раньше даты отправления

## Адаптивность

### Breakpoints:
- 1440px+ - десктопная версия
- 768px-1279px - планшетная версия
- 360px-767px - мобильная версия

### Mobile-first особенности:
- Бургер-меню вместо горизонтальной навигации
- Одноколоночное расположение элементов
- Оптимизированные touch-цели
- Упрощенные формы ввода
